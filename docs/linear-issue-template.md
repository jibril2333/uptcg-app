# Linear → Codex 任务模板

复制以下内容到 Linear Issue，并替换示例。

```markdown
## 目标

一句话描述用户可感知的结果。

## 当前问题

说明现在的行为、复现步骤和相关页面或代码。

## 范围

### 包含

- 本任务必须完成的内容
- 需要新增或修改的测试

### 不包含

- 生产卡牌全量同步
- 真实用户数据迁移
- 自动合并或生产部署

## 验收标准

- [ ] 功能行为符合目标
- [ ] 保持现有功能兼容，或明确说明兼容性变化
- [ ] 添加或更新自动化测试
- [ ] 已运行 `npm run lint`，且没有新增 lint 错误
- [ ] `npm test` 通过（包含生产构建）
- [ ] 不修改真实用户数据

## 开发要求

- 遵守仓库根目录 `AGENTS.md`
- 在独立任务分支开发
- 不自动合并
- 不自动部署生产环境
- 不运行生产卡牌全量同步
- 不访问或修改宿主机持久化数据
- 完成后创建 PR
- PR 中说明测试结果、兼容性和数据影响
```

Issue 准备好后，使用以下评论触发任务：

```text
@Codex 请在 jibril2333/uptcg-app 中实现这个 Issue。
遵守仓库 AGENTS.md，完成后运行并报告 npm run lint 和 npm test，创建 PR，
但不要合并、不要部署、不要运行生产卡牌同步，也不要访问真实用户数据。
```
